# GlassTextField

A labelled single-line text box on glass; `secret` hides what is typed.

- Label above in `label-medium` `text-muted`, `space-xs` gap; box `control-lg` high, `rim` glass, `radius-field`, `space-md` padding; text `body-large`.
- The label is the field's accessible name. Never use a placeholder in its place.
- Use `secret` for passwords and tokens; Beako never logs or displays them afterwards.
