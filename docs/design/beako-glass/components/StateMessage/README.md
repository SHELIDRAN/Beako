# StateMessage

A centred message for empty and error states, with an optional action below.

- Title `title-large` in `text`; optional detail `body-medium` `text-muted`, centred, 420 px wide; 8 px gaps, 48 px vertical padding; the action 8 px further down.
- **Write** a title that states the fact ("No comics match these filters", "Nothing here yet."), a detail only when it helps, and one action that fixes it.
