Neko for Windows 0.4.0 reorganizes Browse around sources, the way Mangayomi does, with MangaDex and Comick as sources.

## Download

Download `Neko-0.4.0-windows-x64.exe` below and run it. It's a single self-contained file with no installer and needs 64-bit Windows 10 or 11. Your library, progress, and settings carry over.

Windows SmartScreen may warn about an unrecognized app because the file isn't code-signed. Choose **More info**, then **Run anyway**. You can check the download against the `.sha256` file.

## New

**Sources.**
- Browse now opens on a list of sources, grouped as Last Used, Pinned, and the rest. Pin the sources you use most to keep them at the top.
- Each source opens with Popular and Latest tabs, its own search, and its own Filters.
- Comick's Popular tab shows its charts (Most Followed New Comics, Most Recent Popular, Trending) for 7 days, 1 month, or 3 months.
- **Search all sources** on the Sources screen shows results from every source side by side, with **See All** to continue in one source.

**Filters per source.**
- Each source declares its own filters, and Neko draws them the same way everywhere: sort orders, check boxes, include/exclude tags, searchable tag lists with counts, sliders, and pickers.
- Your filter choices are saved for each source and come back the next time you open it.

**Comick titles open on MangaDex.** Comick only serves chapters behind a browser check, so clicking a Comick title finds it on MangaDex and opens it there.

## Removed
