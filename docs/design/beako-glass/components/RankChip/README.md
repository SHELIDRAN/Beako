# RankChip

The position badge on ranked shelves: gold, silver and bronze for the top three, dark glass below.

| Rank | Fill | Ink |
| --- | --- | --- |
| 1 | `rank-gold-fill` | `rank-gold-ink` |
| 2 | `rank-silver-fill` | `rank-silver-ink` |
| 3 | `rank-bronze-fill` | `rank-bronze-ink` |
| 4+ | `rank-plain-fill` | `text` |

- `rank-chip` square, `radius-field`, 1 px `rank-rim`, numeral `title-medium`. Sits 10 px in from a card's top-left.
- The number carries the meaning; the metal colours are a bonus, not the signal.
