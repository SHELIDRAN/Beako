# Logo

`logo.webp`: the Beako app logo, 512 × 512. A black-and-white illustrated badge in a round black frame on a crimson square.

- **Small sizes** (the Sidebar panel header, under 48 px): crop it to a circle (`border-radius: 50%; object-fit: cover`) so only the round badge shows.
- **Large sizes** (splash, about screen): show the full square, crimson included.
- Show it on `ground` or `surface`, never on glass over a cover. Never recolour it or redraw it; for anything bigger than 512 px, export again from the original artwork.
